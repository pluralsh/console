* **Fix native workbench log tool query** ([#4528](https://github.com/pluralsh/console/pull/4528)) by @JohnBlackwell

* **Slight tweaks** ([#4533](https://github.com/pluralsh/console/pull/4533)) by @michaeljguarino

  > The Plural Console has been updated to version v0.6.71, which includes important changes to the MCP transport protocol, now exclusively supporting STREAMABLE_HTTP and deprecating SSE. This update enhances synchronization reliability and simplifies the protocol landscape for users. Additionally, various components have been optimized for better performance and usability, including improvements to logging configurations and the introduction of response compression for gRPC services, ensuring a more efficient data transfer.

## New Features 🎉

* **chore(cloud-query): Bump DHI PostgreSQL to 15.19 and rebuild Steampipe extensions with Go 1.27.3** ([#4492](https://github.com/pluralsh/console/pull/4492)) by @maciaszczykm

* **feat: Enable React Compiler, switch to TypeScript 7 and upgrade docs to Next.js 16** ([#4537](https://github.com/pluralsh/console/pull/4537)) by @maciaszczykm

  > React Compiler now compiles `js/console`, `js/design-system` and `js/documentation`. Builds fail if a component can't be compiled (`panicThreshold: all_errors`), and every component compiles.
  > 
  > - Components derive state, reset with a `key` or update in handlers instead of syncing props into state through effects. Modals throw away unsaved edits on close, and refetches no longer overwrite typing (covered by `workbenchForms.test.tsx`). 2,124 components are now memoized automatically, and there are 65 fewer `useEffect` calls.
  > - Paginated queries use typed GraphQL documents, and the generated documents are deduplicated. Every query is identical to master.
  > - Compiler-related fixes: `TabPanel` tabs not switching (covered by `Code.test.tsx`), cluster menu items lost on poll, Helm settings form resetting, `Avatar` showing a stale image, agent runs resending queued prompts, `Radio defaultChecked`.
  > - Unrelated bug fixes:
  >   - Cmd+K Kubernetes Dashboard and Stacks commands opened a broken relative URL outside `/`;
  >   - `IconFrame` ignored explicit icon sizes, so several icons rendered at the wrong size.
  > - Design-system:
  >   - breaking: `NavigationContext` now takes `pathname`/`navigate`, and the package requires React ≥19.2 (`plural/www` needs both to upgrade);
  >   - types are emitted by `tsc` instead of `vite-plugin-dts` and now include the global types the public API uses, so consumers can delete their own copies;
  >   - the Storybook header shows the full Plural logo.
  > - TypeScript 7 everywhere, and TypeScript 6 is removed. `@hey-api/openapi-ts` is pinned to a `next` prerelease until a stable release supports TypeScript 7 (hey-api/hey-api#4235).
  > - Node 26 for the JS workspace, CI and Docker images (it becomes LTS on 2026-10-28). `js/.tool-versions` is the single source of the version, and corepack is now installed explicitly. The agent harness stays on Node 24.
  > - CI now also typechecks docs.
  > - Docs:
  >   - Next.js 16 with Turbopack, `proxy.ts` and `next.config.ts`; standalone output shrinks from 221MB to 156MB;
  >   - Node's built-in TypeScript support replaces `ts-node`;
  >   - `next-env.d.ts` is no longer tracked;
  >   - fixes color mode state handling and a Mermaid SSR crash;
  >   - adds the missing Observability Webhooks page and fixes broken images.
  > - Dependencies are pinned and updated to their latest patch and minor versions, 19 unused packages are removed, and `yarn.lock` is deduped. Renovate now groups related updates and dedupes on every update.
  > - Gains compared to master: typecheck ~40s → ~7s, docs build ~32s → ~14s, design-system build ~10s → ~6s, unit tests ~8s → ~6s, `node_modules` 242MB smaller.
  > - Costs: console production build ~4s → ~17s (compiler Babel pass), initial JS +~470KB gzip (+16%). Runtime re-render gains haven't been profiled yet.
  > - Skip hotkeys while typing in any text field or editor, not just plain inputs. Fixes PROD-5226.
  > - Prevent selecting the same user or group more than once in binding dropdowns. Fixes PROD-5278.
  > - Close setup guide panel when leaving workbench tool create pages. Fixes PROD-5279.
  > - Keep eval prompt code blocks within the summary panel. Fixes PROD-5247.
  > - Fail docs build on undefined Markdoc tags. Fixes PROD-5262.
  > - Set up a publish workflow for @pluralsh/design-system.

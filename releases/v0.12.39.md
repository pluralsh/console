# v0.12.39

## New Features 🎉

* **Compatibility Matrix Update 2026-08-23** ([#4040](https://github.com/pluralsh/console/pull/4040)) by @app/github-actions

  > The compatibility matrix for EKS has been updated to include new versions and their corresponding compatibility with Kubernetes versions. Notably, the addition of version `v4.4.10000020260821-eksbuild.1` and `v0.1.30-eksbuild.1` enhances support for Kubernetes versions 1.30 through 1.36. This update ensures users can leverage the latest features and improvements in their Kubernetes environments while maintaining compatibility with existing services.


## Bug Fixes 🐛

* **Release hotfixes** ([#4042](https://github.com/pluralsh/console/pull/4042)) by @michaeljguarino

  > Hotfixes have been applied to improve the Kubernetes cluster selection experience within the Plural Console. Key updates include enhancements to the ClusterSelector and Cluster components, ensuring that the current cluster is prioritized in the selection and navigation processes. These changes streamline user interactions, reduce errors related to cluster identification, and improve overall dashboard stability during data loading.


## Other Changes

* **Add release notes for v0.12.38** ([#4037](https://github.com/pluralsh/console/pull/4037)) by @app/github-actions

  > Release v0.12.38 introduces significant enhancements, including the transition from HTTPoison to the Req library for improved performance and reliability in HTTP requests, streamlining integrations with services like Azure DevOps and GitHub. Additionally, the compatibility matrix has been updated to support new versions of critical components such as the AWS EC2 Local Instance Store CSI Driver and Elastic Agent, ensuring users can leverage the latest features while maintaining compatibility with their Kubernetes environments. New features like workbench policy support and durable deployment-operator caches further enhance governance, compliance, and deployment efficiency within the Plural Console.

* **Release rapid v0.12.38** ([#4038](https://github.com/pluralsh/console/pull/4038)) by @app/github-actions

This update addresses previous issues and improves overall functionality, ensuring a more reliable and efficient experience for users managing their Kubernetes environments. Additionally, the app version has been incremented to 0.12.38, reflecting these improvements.

# v0.12.55

## New Features 🎉

* **Workbench files design VQA and polish (PROD-5292)** ([#4639](https://github.com/pluralsh/console/pull/4639)) by @wailingwombat

  > The recent update enhances the design and functionality of workbench files within the Plural Console, improving user experience with a polished interface. Key changes include better file attachment options, refined loading indicators, and clearer messaging in modals, which collectively streamline file management and interaction. These improvements not only make the interface more intuitive but also ensure users can manage their files more efficiently, reducing friction during their workflows.

* **Compatibility Matrix Update 2026-11-10** ([#4663](https://github.com/pluralsh/console/pull/4663)) by @app/github-actions

  > The compatibility matrix for EKS has been updated to include new versions and their corresponding compatibility with Kubernetes versions. Notably, several new EKS build versions have been added, ensuring users can leverage the latest features and improvements while maintaining compatibility with Kubernetes versions 1.31 through 1.37. This update enhances the reliability and flexibility of deployments on EKS, allowing users to make informed decisions about their infrastructure.

* **Compatibility Matrix Update 2026-11-10** ([#4664](https://github.com/pluralsh/console/pull/4664)) by @app/github-actions

  > The compatibility matrix has been updated to reflect the latest versions of several key components, including Argo CD, Istio, KServe, Kube Prometheus Stack, and Velero. Notably, this update introduces new chart versions and enhancements such as improved Windows support for Velero and updates to the Kube Prometheus Stack for better observability and scalability. These changes ensure users can leverage the latest features and maintain compatibility with their Kubernetes environments, enhancing overall performance and reliability.

* **Minor ui tweaks** ([#4665](https://github.com/pluralsh/console/pull/4665)) by @michaeljguarino

  > The user interface has received several minor enhancements aimed at improving usability and visual consistency. Key updates include the introduction of a new `WorkbenchPrStatusChip` for displaying pull request statuses, which replaces the previous implementation, and adjustments to the layout of logs and workbench components to better accommodate various screen sizes. These changes enhance the overall user experience by providing clearer information and a more organized interface.

* **Compatibility Matrix Update 2026-11-13** ([#4676](https://github.com/pluralsh/console/pull/4676)) by @app/github-actions

  > The compatibility matrix for various EKS addons has been updated to include new versions and their supported Kubernetes versions. Notably, several addons now support Kubernetes versions down to 1.31, enhancing compatibility and ensuring users can leverage the latest features while maintaining support for older clusters. This update is crucial for users managing diverse Kubernetes environments, as it provides clearer guidance on addon compatibility across different versions.

* **Compatibility Matrix Update 2026-11-13** ([#4677](https://github.com/pluralsh/console/pull/4677)) by @app/github-actions

  > The compatibility matrix has been updated to reflect the latest versions of several Kubernetes add-ons, including the AWS EBS CSI Driver, Argo CD, and the Kube Prometheus Stack. Notably, the AWS EBS CSI Driver has been upgraded to version 1.68.0, which includes enhancements and fixes, while the Kube Prometheus Stack has been updated to version 93.2.2, introducing changes to default ingress settings that may affect existing configurations. These updates ensure users have access to the latest features and improvements, enhancing the stability and functionality of their Kubernetes environments.

* **fix(cloud-query): update remediated provider assets** ([#4678](https://github.com/pluralsh/console/pull/4678)) by @app/plural-copilot

  > Updated the provider asset versions in the cloud-query Dockerfile to ensure compatibility and stability. This change includes upgrades to AWS, Azure, GCP, and vSphere extensions, which enhances the reliability of cloud queries and improves integration with the latest features and fixes from these providers.


## Other Changes

* **Add release notes for v0.12.54** ([#4656](https://github.com/pluralsh/console/pull/4656)) by @app/github-actions

  > Release v0.12.54 introduces significant enhancements, including the implementation of Cosign for all console images, which bolsters security by ensuring only verified images are deployed. This release also optimizes agent runs for better performance and introduces a streamlined Home setup card, enhancing the onboarding experience for new users.

* **Release v0.12.54** ([#4657](https://github.com/pluralsh/console/pull/4657)) by @app/github-actions

Additionally, the app version for both the console and datastore has been updated to 0.12.54 and 0.0.97 respectively, ensuring users benefit from the latest features and improvements. This release aims to provide a more robust and efficient experience for managing Kubernetes environments.

* **Release rapid v0.12.54** ([#4658](https://github.com/pluralsh/console/pull/4658)) by @app/github-actions

Additionally, the Chart version has been incremented to 0.4.58, reflecting these changes.

# v0.12.52

## New Features 🎉

* **feat: enhance insights with service context and custom priority scripting and rework health score** ([#4514](https://github.com/pluralsh/console/pull/4514)) by @floreks

  > Enhanced insights now include the ability to define custom priority scripting for service components, allowing users to tailor the health scoring of Kubernetes resources based on specific criteria. This feature enables more granular control over resource management, improving the accuracy of health assessments and facilitating better decision-making in operational contexts. Additionally, the health score calculation has been reworked to integrate these custom priorities, ensuring that insights reflect the most relevant operational metrics.

* **feat: agent run reprompting** ([#4524](https://github.com/pluralsh/console/pull/4524)) by @zreigz

  > Agent run reprompting has been enhanced to allow for follow-up prompts to be requeued effectively, ensuring that pending agent runs can be resumed without delay. This improvement enables a more responsive workflow by recreating agent run pods for pending follow-ups, thereby reducing idle time and improving the overall efficiency of the deployment process. Additionally, a new session URL feature has been introduced, allowing users to access uploaded session artifacts directly, streamlining the review and troubleshooting process.

* **Expand Atlassian/Jira workbench integration documentation** ([#4549](https://github.com/pluralsh/console/pull/4549)) by @app/plural-copilot

  > The documentation for the Atlassian workbench integration has been significantly expanded to include detailed instructions for connecting to both Jira and Confluence Cloud via Atlassian's Model Context Protocol (MCP) server. Users can now perform a wider range of operations, such as searching, creating, and updating issues, as well as reading and editing pages, enhancing their ability to manage tasks directly from the workbench. This update streamlines the integration process and improves user experience by providing comprehensive setup guidance and troubleshooting tips.

* **docs: expand log aggregation tool integration pages** ([#4550](https://github.com/pluralsh/console/pull/4550)) by @app/plural-copilot

  > The documentation for log aggregation tool integrations has been significantly expanded to provide clearer guidance on using Elasticsearch, Loki, Splunk, and VictoriaLogs within Plural's workbench environment. Each integration page now includes detailed instructions on setup, query capabilities, and troubleshooting, enhancing user experience and enabling more effective log management and analysis. This update is crucial for users looking to streamline their logging processes and leverage the full potential of these tools in their Kubernetes environments.

* **Docsite Redesign** ([#4552](https://github.com/pluralsh/console/pull/4552)) by @michaeljguarino

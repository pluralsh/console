# v0.12.43

## New Features 🎉

* **Compatibility Matrix Update 2026-09-12** ([#4313](https://github.com/pluralsh/console/pull/4313)) by @app/github-actions

  > The compatibility matrix for the EKS add-ons has been updated to include new versions, specifically v1.9.2-eksbuild.1, v4.0.10000020260910-eksbuild.1, v1.22.10000020260909-eksbuild.1, and v8.6.0-eksbuild.8, along with their supported Kubernetes versions ranging from 1.30 to 1.36. This enhancement ensures users can leverage the latest add-on features while maintaining compatibility with their existing Kubernetes clusters, thereby improving operational efficiency and reducing potential integration issues.

* **Compatibility Matrix Update 2026-09-12** ([#4315](https://github.com/pluralsh/console/pull/4315)) by @app/github-actions

  > The compatibility matrix has been updated to reflect the latest versions of various Kubernetes add-ons, including Amazon VPC CNI, Argo CD, and External DNS. Key updates include the introduction of new features such as cross-namespace watch support for External DNS and secret-based authentication for control-plane ServiceMonitors in the kube-prometheus-stack. These enhancements improve functionality and security, ensuring users can leverage the latest capabilities in their Kubernetes environments.

* **Prep v0.12.43** ([#4316](https://github.com/pluralsh/console/pull/4316)) by @michaeljguarino

  > The release of version v0.12.43 introduces several updates, including an upgrade to Go version 1.27.1 across multiple components, enhancing compatibility and performance. Additionally, the agent version has been updated to v0.6.64, ensuring users benefit from the latest features and fixes. This release also includes improvements to CI workflows and dependency management, streamlining the development process and reducing potential issues during builds.


## Bug Fixes 🐛

* **Fix chat completions compatibility in opencode and PI** ([#4314](https://github.com/pluralsh/console/pull/4314)) by @michaeljguarino

  > Chat completions compatibility has been enhanced for both OpenCode and Pi configurations, allowing users to specify the OpenAI API method used for interactions. This update introduces a new `Method` field that enables selection between different API endpoints, such as `/chat/completions` and `/responses`, improving flexibility and control over AI integrations. This change ensures that users can better tailor their AI interactions to meet specific application needs, enhancing the overall functionality of the deployment operator.


## Other Changes

* **Add release notes for v0.12.42** ([#4310](https://github.com/pluralsh/console/pull/4310)) by @app/github-actions

  > Version v0.12.42 introduces several significant enhancements to the Plural Console, including a new "repositoryImage" field in the AgentRuntimeSpec for improved efficiency when accessing multiple repositories, and integrated tracing support for better observability of job activities. Additionally, users can now configure the Git server image pull policy through the Helm chart, and new workbench dashboards have been added to streamline monitoring. These updates collectively enhance user experience, operational efficiency, and management capabilities within Kubernetes environments.

## Bug Fixes 🐛

* **refactor(client): switch to sanitized console client across client implementations** ([#4096](https://github.com/pluralsh/console/pull/4096)) by @floreks

  > The client implementations have been refactored to utilize a sanitized console client, enhancing security by preventing the exposure of GraphQL response bodies in error messages. This change ensures that sensitive information is not leaked in error responses, thereby improving the overall security posture of the application when handling GraphQL operations.

* **fix(workbench): remove overflow from activity to fix scrollbar flickering issue** ([#4098](https://github.com/pluralsh/console/pull/4098)) by @floreks

  > The overflow property has been removed from the Workbench Job Activity component, resolving an issue where the scrollbar flickered during activity updates. This enhancement improves the user experience by providing a smoother and more visually stable interface while interacting with job activities in the workbench.

* **Workbench improvements** ([#4104](https://github.com/pluralsh/console/pull/4104)) by @michaeljguarino

  > The latest update introduces significant improvements to the workbench functionality, enhancing user experience and operational efficiency. Key changes include the addition of TLS certificate management for secure connections, updates to the deployment configurations for better integration with KAS and Nexus services, and refined handling of job activities and alerts within the workbench interface. These enhancements ensure a more secure and streamlined workflow for users managing Kubernetes deployments.

* **Fixes for grpc connection handling** ([#4120](https://github.com/pluralsh/console/pull/4120)) by @michaeljguarino

  > The gRPC connection handling has been improved by switching the adapter from Mint to Gun, enhancing the reliability of connections. Additionally, the retry logic has been refined to prevent retries on specific lambda invocations, ensuring more predictable behavior during error scenarios. This change is crucial for maintaining stable and efficient communication with cloud services, reducing unnecessary retries and improving overall performance.

* **refactor(client): switch to sanitized console client across client implementations** ([#4096](https://github.com/pluralsh/console/pull/4096)) by @floreks

  > The client implementation has been refactored to utilize a sanitized console client, enhancing security by preventing sensitive GraphQL response bodies from being exposed in error messages. This change ensures that errors are logged without revealing potentially sensitive information, improving the overall security posture of the application while maintaining the ability to diagnose issues effectively. Users can now expect a more secure interaction with the console client, reducing the risk of accidental data leaks during error handling.

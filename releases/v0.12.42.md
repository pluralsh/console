# v0.12.42

## New Features 🎉

* **feat: repository prebake for agent runtimes** ([#4070](https://github.com/pluralsh/console/pull/4070)) by @zreigz

  > The new feature introduces a "repositoryImage" field to the AgentRuntimeSpec, allowing users to specify an OCI image that contains precloned git repositories. This enhancement enables an init container to copy these repositories into a shared directory, streamlining the process by allowing local repository access instead of requiring a git clone. This change significantly improves efficiency for users working with multiple repositories in their Kubernetes environments.

* **feat: Tracing support** ([#4110](https://github.com/pluralsh/console/pull/4110)) by @maciaszczykm

  > Tracing support has been integrated into the Plural Console, enhancing the observability of job activities within workbenches. Users can now view detailed trace information alongside metrics and logs, allowing for improved troubleshooting and performance analysis of Kubernetes jobs. This feature is crucial for identifying bottlenecks and understanding the flow of operations, ultimately leading to more efficient management of Kubernetes deployments.

* **Compatibility Matrix Update 2026-09-07** ([#4119](https://github.com/pluralsh/console/pull/4119)) by @app/github-actions

  > The compatibility matrix for EKS has been updated to include new versions, specifically v4.4.10002020260905-eksbuild.1, v1.22.10004020260905-eksbuild.1, and v0.0.10009020260905-eksbuild.1, along with their compatibility with Kubernetes versions 1.30 through 1.35. This enhancement ensures users can leverage the latest EKS builds while maintaining compatibility with their existing Kubernetes environments, facilitating smoother upgrades and deployments.

* **Compatibility Matrix Update 2026-09-07** ([#4122](https://github.com/pluralsh/console/pull/4122)) by @app/github-actions

  > The compatibility matrix has been updated to include version 90.0.0 for the kube-prometheus-stack, which introduces secret-based authentication support for control-plane ServiceMonitors, enhancing security by enabling the scraping of secured endpoints using Kubernetes Secrets. Additionally, the chart version for Argo CD has been incremented to 10.8.1, reflecting updates that may include security and bug fixes. These changes improve the overall security and functionality of the deployment environment for users.

* **feat(chart): configure git-server image pull policy** ([#4124](https://github.com/pluralsh/console/pull/4124)) by @app/plural-copilot

  > The Git server image pull policy can now be configured through the Helm chart, allowing users to set a custom pull policy based on their deployment needs. This enhancement provides greater flexibility in managing image updates and resource utilization, ensuring that users can optimize their Kubernetes environments according to their specific requirements.

* **Add workbench dashboards** ([#4128](https://github.com/pluralsh/console/pull/4128)) by @michaeljguarino

  > Workbench dashboards have been added, enhancing the observability capabilities within the Plural Console. This feature allows users to create, manage, and visualize dashboards tailored to their specific monitoring needs, streamlining the process of tracking performance and health metrics across Kubernetes environments. By integrating these dashboards, users can gain deeper insights into their workloads, improving overall operational efficiency and responsiveness.

* **feat: Showing users in groups** ([#4161](https://github.com/pluralsh/console/pull/4161)) by @maciaszczykm

  > Users can now view group memberships directly within the Plural Console, enhancing user management capabilities. This feature allows administrators to see which users belong to specific groups, streamlining the process of managing user access and roles. Additionally, the new interface includes pagination for easier navigation through larger groups, making it more efficient to manage memberships at scale.

* **docs: clarify monthly contributor award limit** ([#4187](https://github.com/pluralsh/console/pull/4187)) by @app/plural-copilot

  > The monthly contributor award program now includes a clarification that contributors are limited to one award per calendar month. This change ensures the sustainability of the program and allows reviewers to dedicate appropriate attention to each submission, enhancing the overall quality of contributions.

* **Compatibility Matrix Update 2026-09-09** ([#4238](https://github.com/pluralsh/console/pull/4238)) by @app/github-actions

  > The compatibility matrix has been updated to reflect the latest versions and enhancements for various Kubernetes integrations, including Argo CD, Chaos Mesh, and Istio. Notably, security patches addressing CVE-2026-35469 have been incorporated, along with improvements in traffic routing and dashboard functionality. * **feat: Update flows** ([#4275](https://github.com/pluralsh/console/pull/4275)) by @maciaszczykm

## Bug Fixes 🐛

* **Polishing wb monitoring view** ([#4402](https://github.com/pluralsh/console/pull/4402)) by @michaeljguarino

  > The monitoring view for workbenches has been enhanced with improved loading states and input readiness checks, ensuring a smoother user experience when interacting with dashboards. Users will now see a loading skeleton while the dashboard is preparing, and the interface will only display the dashboard panels once all necessary inputs are ready, reducing confusion and improving overall usability. This update streamlines the monitoring process, making it more intuitive and responsive for users managing their Kubernetes environments.

* **fix: Fix dashboard fragments** ([#4410](https://github.com/pluralsh/console/pull/4410)) by @maciaszczykm

  > Dashboard fragments have been updated to remove the `options` and `input` fields from the GraphQL schema, addressing issues with JSON decoding in the Console. This change enhances the reliability of data retrieval for dashboard components, ensuring smoother operation and improved user experience when interacting with monitoring features. The omitted fields will be reintroduced once the output field supports the Map scalar, allowing for more flexible data handling in the future.

* **feat: Declare dashboard JSON outputs as map** ([#4415](https://github.com/pluralsh/console/pull/4415)) by @maciaszczykm

  > Dashboard JSON outputs are now declared as maps, enhancing the flexibility and usability of dashboard configurations. This change allows for more complex options and input structures to be defined within the dashboard graphs and datasources, improving the overall user experience in customizing and managing observability tools. As a result, users can expect better integration and functionality when working with dashboard elements in the Plural Console.

* **Devboxes work** ([#4686](https://github.com/pluralsh/console/pull/4686)) by @michaeljguarino

  > This will implement interactive cloud based coding agents within workbenches.  Basic features are:
  > 
  > 1. Leverage agent substrate to handle sandbox mechanics, vm isolation, pause, snapshot and resume
  > 2. GRPC tunnel based reverse tunneling via a gateway daemon managed by our operator to both expose a grpc control api to console and report needed feedback
  > 3. Auto-suspend from w/in the sandbox in the event agents no longer are working
  > 4. ACP based control of mainstream agents, like in agent runtime, but lets their session state remain source of truth vs cloning it into our db
  > 5. Auto-wiring our scm connection credentials, mcp server, etc
  > 6. OIDC based workload identity to federate creds to cloud providers as needed.

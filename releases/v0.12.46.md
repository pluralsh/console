# v0.12.46

## New Features 🎉

* **Compatibility Matrix Update 2026-09-19** ([#4365](https://github.com/pluralsh/console/pull/4365)) by @app/github-actions

  > The compatibility matrix has been updated to include Argo Workflows version 4.1.4, which is now compatible with Kubernetes versions 1.34, 1.35, and 1.36. This update also reflects changes in the chart version to 2.0.7 and updates the associated images to their latest versions, ensuring users have access to the most recent features and fixes for improved performance and stability.

* **Compatibility Matrix Update 2026-09-20** ([#4374](https://github.com/pluralsh/console/pull/4374)) by @app/github-actions

  > The compatibility matrix has been updated to include new versions for several EKS add-ons, such as the Amazon SageMaker Hyperpod Inference and the AWS Network Flow Monitoring Agent, now supporting Kubernetes versions down to 1.30. This enhancement ensures users can leverage the latest features and improvements of these add-ons while maintaining compatibility with older Kubernetes versions, thereby facilitating smoother upgrades and deployments within their environments.

* **Compatibility Matrix Update 2026-09-21** ([#4377](https://github.com/pluralsh/console/pull/4377)) by @app/github-actions

  > The compatibility matrix for the EKS add-ons has been updated to include new versions for the `aws-efs-csi-driver-fips`, `aws-vpc-cni-fips`, and other components, ensuring support for Kubernetes versions 1.30 through 1.35. This update is crucial for users to maintain compatibility with the latest Kubernetes releases and to leverage new features and improvements in their deployments.

* **Compatibility Matrix Update 2026-09-21** ([#4379](https://github.com/pluralsh/console/pull/4379)) by @app/github-actions

  > The compatibility matrix has been updated to include detailed summaries for Argo Workflows versions v4.1.0 and v4.1.4, highlighting key features, chart updates, and installation manifest changes. Users can now easily access information about new features and any breaking changes by referring to the external blog and upgrading guide, ensuring a smoother transition when upgrading their deployments. This update enhances clarity and aids in maintaining compatibility with Kubernetes versions 1.34 to 1.36.


## Bug Fixes 🐛

Additionally, various bug fixes enhance the overall stability and performance of the console.

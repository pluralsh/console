# v0.12.44

## New Features 🎉

* **feat(acp): integrate ACP harness for agent communication** ([#4072](https://github.com/pluralsh/console/pull/4072)) by @floreks

  > The integration of the ACP harness for agent communication enhances the Plural deployment operator by enabling more efficient and streamlined interactions between agents. This update includes updated versions of various agent components, ensuring improved performance and compatibility. Users will benefit from enhanced capabilities in managing agent communications, leading to a more robust and responsive Kubernetes management experience.

* **Add loading icon for waiting subagents** ([#4111](https://github.com/pluralsh/console/pull/4111)) by @wailingwombat

  > A new loading icon has been introduced for waiting subagents in the Plural Console, enhancing the user experience by providing visual feedback during processing. This change allows users to easily identify when a subagent is active, improving clarity and reducing confusion during interactions with the AI chatbot. The addition of the `AgentLoadingIcon` ensures that users are informed of ongoing operations, which is crucial for maintaining a smooth workflow.

* **refactor: Remove honorable, update dependencies and move stylelint-config to js workspace** ([#4308](https://github.com/pluralsh/console/pull/4308)) by @maciaszczykm

  > The Plural Console has been updated to enhance its code quality and maintainability by removing the Honorable theme provider and updating various dependencies, including significant upgrades to libraries like `styled-components` and `react-router`. Additionally, a new workflow for publishing the Stylelint configuration has been introduced, allowing for better management of CSS linting rules. These changes streamline the development process and ensure a more robust and consistent user experience across the platform.

* **Compatibility Matrix Update 2026-09-13** ([#4322](https://github.com/pluralsh/console/pull/4322)) by @app/github-actions

  > The compatibility matrix for the EKS add-on has been updated to include a new version of `chainguard_coredns-fips` (v1.47.10000020260911-eksbuild.1), which is now compatible with Kubernetes versions 1.33, 1.34, and 1.35. This update ensures that users can leverage the latest features and improvements of the add-on while maintaining compatibility with their existing Kubernetes clusters.

* **Compatibility Matrix Update 2026-09-14** ([#4324](https://github.com/pluralsh/console/pull/4324)) by @app/github-actions

  > The compatibility matrix for the EKS add-ons has been updated to include version v4.5.10000020260912-eksbuild.1, which is compatible with Kubernetes versions 1.30 through 1.35. This enhancement ensures users can leverage the latest EKS add-on while maintaining compatibility with a broader range of Kubernetes versions, improving flexibility and support for diverse deployment scenarios.

* **Compatibility Matrix Update 2026-09-14** ([#4325](https://github.com/pluralsh/console/pull/4325)) by @app/github-actions

  > The compatibility matrix has been updated to include new versions 91.2.1 and 90.2.0 for the kube-prometheus-stack, which are now compatible with Kubernetes versions 1.25 through 1.36. Notably, version 91.2.1 introduces a significant change in how webhook `matchConditions` are rendered, now requiring a YAML list format to avoid misconfigurations, along with a dependency bump for the `prometheus-node-exporter` container image. Users should validate their generated manifests before upgrading to ensure compatibility with these changes.

* **workbench task to mcp** ([#4327](https://github.com/pluralsh/console/pull/4327)) by @kinjalh

  > A new workbench task has been implemented to enable the integration of the workbench's toolset with an MCP (Multi-Channel Protocol) server. This enhancement allows external agents to interact with the tools configured on a workbench, facilitating more flexible automation and integration scenarios. By binding the workbench and user context, this feature streamlines tool usage and enhances the overall functionality of the workbench environment.

* **Workbench ui tweaks** ([#4328](https://github.com/pluralsh/console/pull/4328)) by @michaeljguarino

  > The latest update introduces several UI enhancements to the Workbench, improving user experience and accessibility. Key changes include the addition of customizable settings for visibility of various tabs within the Console settings page, allowing users to tailor their interface according to their preferences. This flexibility enhances usability, making it easier for users to manage their workflows and access relevant features efficiently.

* **Compatibility Matrix Update 2026-09-15** ([#4331](https://github.com/pluralsh/console/pull/4331)) by @app/github-actions

  > The compatibility matrix for the EKS add-ons has been updated to include new versions and their corresponding Kubernetes compatibility. Notably, versions like `v1.66.0-eksbuild.1` and `v3.2.4-eksbuild.1` now support a wider range of Kubernetes versions, enhancing user flexibility in selecting compatible add-ons for their deployments. This update ensures that users can leverage the latest features and improvements while maintaining compatibility with their existing Kubernetes environments.

* **Compatibility Matrix Update 2026-09-16** ([#4339](https://github.com/pluralsh/console/pull/4339)) by @app/github-actions

Users can now leverage the latest features and fixes from these add-ons while maintaining compatibility with their existing Kubernetes environments.

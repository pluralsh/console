# v0.12.49

## New Features 🎉

* **feat(sync-options): add support for Prune=False annotation** ([#4416](https://github.com/pluralsh/console/pull/4416)) by @floreks

  > Support for the `Prune=False` annotation has been added, allowing users to prevent the deletion of resources when synchronizing with Kubernetes. This enhancement is crucial for maintaining resource integrity during updates, ensuring that important configurations remain intact even when they are not actively managed. This change improves the flexibility and control users have over their deployment processes, particularly in complex environments.

* **feat: Expose service warnings in Lua and Python templating** ([#4417](https://github.com/pluralsh/console/pull/4417)) by @maciaszczykm

  > Service warnings can now be reported in both Lua and Python templating, allowing scripts to issue non-fatal warnings that indicate a service is stale. This enhancement improves the visibility of potential issues during service deployment, enabling users to proactively address concerns without halting their workflows. By incorporating these warnings, users can better manage their Kubernetes services and maintain operational efficiency.

* **fix(security): remediate PROD-5198 dependencies and container runtime alerts** ([#4429](https://github.com/pluralsh/console/pull/4429)) by @app/plural-copilot

  > Security enhancements have been implemented to address vulnerabilities identified in various dependencies and container runtimes, specifically remediating issues related to OpenSSL and libexpat. Additionally, health checks have been added to multiple Dockerfiles, ensuring improved monitoring and reliability of services. These updates are crucial for maintaining a secure and stable production environment, reducing the risk of potential exploits and enhancing overall system resilience.

* **Compatibility Matrix Update 2026-09-28** ([#4432](https://github.com/pluralsh/console/pull/4432)) by @app/github-actions

## Bug Fixes 🐛

* **move publish from gcr to pkg.dev** ([#4428](https://github.com/pluralsh/console/pull/4428)) by @michaeljguarino

  > The publishing process for Helm charts has been updated to use Google's Artifact Registry instead of Google Container Registry (GCR). This change enhances the deployment workflow by providing a more streamlined and efficient method for managing Helm charts, ensuring better integration with Google's cloud services. Users will now benefit from improved access and management capabilities for their Kubernetes applications.

* **Simplify nexus healthchecks** ([#4446](https://github.com/pluralsh/console/pull/4446)) by @michaeljguarino

  > Nexus health checks have been simplified by allowing health endpoints to be accessed without a prefix, enabling load balancers to probe these endpoints directly. This change enhances the reliability of health checks across backends, ensuring that services can be monitored more effectively. Additionally, the implementation includes new tests to verify the functionality of the updated routing behavior.

* **Switch code font to JetBrains Mono** ([#4448](https://github.com/pluralsh/console/pull/4448)) by @wailingwombat

  > The code font for the Plural Console has been updated to JetBrains Mono, enhancing the readability and aesthetic appeal of code snippets across the interface. This change replaces the previous Monument Mono font, providing a more modern and consistent look, which is particularly beneficial for users working with code and logs. The switch to JetBrains Mono is expected to improve the overall user experience by making text easier to read and navigate.

* **Compatibility Matrix Update 2026-08-04** ([#3956](https://github.com/pluralsh/console/pull/3956)) by @app/github-actions

  > The compatibility matrix has been updated to reflect the new version 3.5.0 of the AWS Load Balancer Controller, which introduces significant enhancements including support for Gateway API v1.6.0 and improved certificate management features. Users must update their Gateway API CRDs to v1.6.0 prior to upgrading the controller to avoid disruptions in NLB Gateway L4 routing. This update also deprecates the `v1beta1` storage version, ensuring a smoother transition for users managing their Kubernetes environments.

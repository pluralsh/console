## New Features 🎉

* **httpoison to req** ([#3928](https://github.com/pluralsh/console/pull/3928)) by @kinjalh

  > The HTTP client library has been updated from HTTPoison to Req across various modules, enhancing the performance and reliability of HTTP requests within the Plural Console. This change streamlines the integration with external services like Azure DevOps, Bitbucket, and GitHub, ensuring more efficient handling of requests and responses. Users can expect improved error handling and reduced latency in API interactions, contributing to a smoother experience when managing Kubernetes workloads.

* **Compatibility Matrix Update 2026-08-15** ([#4008](https://github.com/pluralsh/console/pull/4008)) by @app/github-actions

## Bug Fixes 🐛

* **fix(ai-proxy): isolate Mantle SigV4 request targets** ([#4012](https://github.com/pluralsh/console/pull/4012)) by @app/plural-copilot

  > The Mantle SigV4 request targets have been isolated to enhance security and functionality within the AI proxy. This change ensures that requests to the Mantle service are properly authenticated without exposing sensitive authorization tokens, thereby improving the integrity of interactions with both the Mantle and OpenAI APIs. Additionally, new tests have been introduced to verify that responses remain isolated and correctly routed, ensuring a more robust and secure integration.

* **fix: Pi proxy mode** ([#4032](https://github.com/pluralsh/console/pull/4032)) by @zreigz

  > The Pi proxy mode has been updated to ensure that when proxying is enabled, the provider key is set to "plural" instead of "openai." This change prevents the Pi CLI from stripping the "openai/" prefix from model IDs, ensuring that the full provider/model format is correctly sent to the Plural AI proxy. This enhancement improves the integration with the Plural AI proxy, facilitating more accurate communication and functionality when using proxy configurations.

The Cloud tool gives a workbench agent SQL access to an AWS, GCP, or Azure account through a Plural cloud connection. The same tool type covers all three providers; the connection selects the account.

## Capabilities

* $DOCSTUB: name the query operations in `lib/console/ai/tools/workbench/infrastructure/` and `go/cloud-query/internal/tools/`.
* $DOCSTUB: mention permissions only when the implementation or a cloud connection guide states them.

## Setup

There is no inline tool setup guide for Cloud yet. Credentials come from a cloud connection, maintained under `js/console/public/setup-guides/cloud-connections/`.

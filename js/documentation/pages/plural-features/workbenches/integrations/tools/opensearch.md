The OpenSearch tool lets a workbench agent search an OpenSearch index, including an Amazon OpenSearch Service domain. Configure the connection once, then attach it to the workbenches that should use it.

## Setup

Create the tool under **Workbenches → Integrations** and follow the inline setup guide for credentials and Console fields. That guide is maintained at `js/console/public/setup-guides/tools/opensearch.md`.

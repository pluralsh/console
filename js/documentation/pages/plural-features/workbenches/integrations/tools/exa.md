The Exa tool lets a workbench agent call the Exa API. Plural Cloud can supply a built-in key; otherwise configure your own API key, then attach the tool to the workbenches that should use it.

## Setup

Create the tool under **Workbenches → Integrations** and follow the inline setup guide for credentials and Console fields. That guide is maintained at `js/console/public/setup-guides/tools/exa.md`.

The Azure Function tool lets a workbench agent invoke an Azure Function through a Plural cloud connection. The tool stores a resource identifier, a description, and an input schema.

There is no inline tool setup guide for Azure Function yet. It uses an Azure cloud connection. Connection setup is maintained at `js/console/public/setup-guides/cloud-connections/azure.md`.

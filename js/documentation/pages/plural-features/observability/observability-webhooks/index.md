---
title: Observability Webhooks
description: Receive metrics, logs, and alerts from Datadog or Grafana in the Plural Console
---

Observability webhooks connect an external monitoring system to the Plural Console so metrics, logs, and alerts show up alongside the resources they describe. Create one from `Settings > Global Settings > Observability > Webhooks`, then point the provider at the URL Plural generates.

- [Datadog](/plural-features/observability/observability-webhooks/datadog)
- [Grafana](/plural-features/observability/observability-webhooks/grafana)

Workbench jobs can also start from alert payloads. That setup lives under [workbench webhooks](/plural-features/workbenches/integrations/webhooks).

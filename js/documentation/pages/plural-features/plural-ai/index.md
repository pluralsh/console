title: Plural AI
description: Plural's AI engine removes the gruntwork from infrastructure
---

Managing infrastructure is full of mind-numbing tasks, from troubleshooting the same misconfiguration for the hundredth time, to whack-a-moling Datadog alerts, to playing internal IT support for application developers who cannot be bothered to learn the basics of foundational technology like Kubernetes.  Plural AI allows you to outsource all those time-sucks to LLMs so you can focus on building robust platforms for your enterprise.

In particular, Plural AI's approach has a few differentiators:

* Bring-your-own-LLM - allows you to use the LLM already approved by your enterprise without worrying about us as a MITM
* Self-Hostability - allows you to maintain full data sovereignty.  We aren't an AI lab, and don't need to train on your data.
* An always-on troubleshooting engine - takes signals from failed Kubernetes services, failed Terraform runs, and other misfires in your infrastructure to run a consistent investigative process and summarize the results.  Eliminate manual digging and fix the issue instead.  Think of this as a Cursor Tab for infra.
* Remote Coding Agents on K8s - allows you to run infinitely parallelizable coding agents via API on your existing Kubernetes infrastructure, with us handling the scheduling and developer experience end to end.

And finally, our main AI feature is [Workbenches](/plural-features/workbenches): fully hosted agents with built-in policy enforcement for automating end-to-end work as a platform engineer. Read the [Workbenches documentation](/plural-features/workbenches) to see what they can do.
